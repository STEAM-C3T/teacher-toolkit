# Module 2: HTML Foundations

## Assessment Rubric — HTML Foundations

Use the same four performance levels across the module rubrics. Score each criterion from 1–4 and record the evidence observed or collected.

| Criterion | Emerging (1) | Developing (2) | Proficient (3) | Advanced (4) | Evidence to collect |
|---|---|---|---|---|---|
| Semantic content | Headings, links, or lists are missing or used inconsistently. | Includes required elements but some structure or link text is unclear. | Uses logical headings, appropriate lists, descriptive links, and image alternatives. | Combines semantic elements with clear hierarchy and a well-structured figure/caption. | Submitted HTML page and heading/link scan. |
| Forms | Controls are missing labels or labels do not identify their controls. | Some controls are labeled, but associations or instructions are incomplete. | Every control has an associated label and suitable input type; required fields are clear. | Adds useful instructions or validation feedback and verifies keyboard use. | Form source and keyboard demonstration. |
| Tables | Data is missing or row/column meaning is unclear. | Uses table cells but headers or purpose are incomplete. | Uses headers correctly and presents a readable small dataset. | Adds a concise caption and clear relationships for complex data. | Table markup and rendered table. |
