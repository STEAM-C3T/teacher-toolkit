# Module 6: Creative Web Projects

## Assessment Rubric — Generative/Creative Artefact

### Competence mapping (DigComp 2.2)

- 3.1 Developing digital content
- 3.2 Integrating and re-elaborating
- 5.1 Problem solving
- 5.3 Creativity and innovation

Use the same four performance levels across the module rubrics. Score each criterion from 1–4 and record the evidence observed or collected.

| Criterion | Emerging (1) | Developing (2) | Proficient (3) | Advanced (4) | Evidence to collect |
|---|---|---|---|---|---|
| Functionality and control | Controls are missing or do not affect the output. | One control works, but ranges or feedback are unclear. | Two or more controls reliably change output within useful ranges. | Controls are intuitive and prevent or explain likely failure states. | Working artefact and control demonstration. |
| Visual coherence | Visual output appears incomplete or has no stated intent. | Some visual choices are deliberate, but composition is inconsistent. | Palette and composition support the stated intent. | Iteration produces a cohesive result with a clear rationale. | Artefact plus before/after or iteration notes. |
| Technical quality | Code is fragile or prevents the artefact from working. | Core code works with some errors or unnecessary complexity. | Code is readable and performs reliably for the chosen scope. | Structure supports further changes and avoids unnecessary work. | Source file and successful run. |
| Accessibility and explanation | No caption/description or motion control where needed. | Provides a partial description or basic control. | Describes behavior and controls; motion can be paused when animated. | Explains audience choices and verifies keyboard/reduced-motion behavior. | Caption, keyboard check, and pause/reduced-motion observation. |
