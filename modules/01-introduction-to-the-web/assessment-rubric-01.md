# Module 1: Introduction to the Web

## Assessment Rubric — Introduction to the Web

Use the same four performance levels across the module rubrics. Score each criterion from 1–4 and record the evidence observed or collected.

| Criterion | Emerging (1) | Developing (2) | Proficient (3) | Advanced (4) | Evidence to collect |
|---|---|---|---|---|---|
| Web model | Names a browser or website but cannot describe a request. | Describes part of the browser–server exchange with prompts. | Explains browser request, server response, and page display in order. | Explains the sequence and applies it to a new example or a delay/error. | Three-step flow diagram or oral explanation. |
| Semantic structure | HTML elements are missing or used without clear roles. | Identifies some document elements or landmarks. | Correctly identifies `html`, `head`, `body` and uses semantic landmarks. | Explains how the structure supports page meaning and navigation. | Completed HTML page or annotated starter. |
| Accessible content | Language, links, headings, or image alternatives are missing or unclear. | Includes some accessible content but leaves notable gaps. | Uses meaningful headings and links, `lang`, and appropriate image `alt` text. | Checks keyboard navigation and explains a content decision. | Page review checklist and keyboard observation. |
