# Module 4: JavaScript Essentials

## Assessment Rubric — JavaScript Essentials

Use the same four performance levels across the module rubrics. Score each criterion from 1–4 and record the evidence observed or collected.

| Criterion | Emerging (1) | Developing (2) | Proficient (3) | Advanced (4) | Evidence to collect |
|---|---|---|---|---|---|
| Event handling | Interaction does not reliably respond or uses inline handlers. | Event is connected, but behavior or feedback is incomplete. | Uses an event listener and named function for the expected interaction. | Separates logic into reusable functions and handles relevant edge cases. | Code snippet and observed interaction. |
| State and rendering | State is missing or displayed output becomes inconsistent. | State exists, but some updates do not match the interface. | State updates predictably and the rendered view reflects it. | Clear state structure and render flow handle filtered or alternate views. | State trace plus before/after UI. |
| Accessibility | Controls lack labels or dynamic feedback is unavailable. | Some controls and changes are accessible, with gaps. | Controls are labeled, keyboard operable, and changes are perceivable. | Manages focus and feedback thoughtfully across interaction states. | Keyboard check and visible/live result. |
